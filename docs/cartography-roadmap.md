# 制图与成果输出：后续开发任务

更新日期：2026-09-10；原规划日期：2026-09-09。

状态：依据用户提供的“GIS 制图与成果输出”和“程序规则 + Agent/Skill”两份材料维护路线图。Phase4A1 / 0.7.0正在交付CART-01A：手动矢量样式与已配置符号图例，范围见[阶段说明](phase-4a1.md)。CART-00是历史独立实验；产品 Layout、正式制图导出和 Agent 尚未实现。

## 1. 采用方向与优先级

后续采用 `Cartography Engine + Cartography Skills` 的分工：程序验证并执行版本化的制图配置，Agent 提出可检查、可撤销的设计建议。目标是手工设置、内置模板与 Agent 共用同一个配置和渲染路径，基础制图离线可用、不依赖模型；这些属于产品设计要求，并非当前已交付能力。

| 路线 | 收益 | 代价与决定 |
| --- | --- | --- |
| 全部采用固定模板 | 稳定、离线、易复现 | 数据与专题变化时表达受限，保留为基础能力 |
| 全部由 Agent 自由绘图 | 建议灵活 | 难以约束数据、版式和复现，不能作为正式输出路径 |
| 程序规则 + 结构化配置 + 可选 Agent | 同时支持稳定输出与设计建议 | 需维护配置版本、验证器及渲染一致性；采用此路线 |

主线仍为 Phase 1 数据基础、Phase 2 用地叠加/面积统计、Phase 3 交付稳定性。Phase 4 先交付土地利用成果图，再增加地形影像和高级出版输出；Phase 5 接入制图顾问。人口、交通、生态等材料中的例子仅是未来模板候选，不因此新增对应分析模块。

| 阶段 | 纳入任务 | 进入与完成条件 |
| --- | --- | --- |

| Phase 2 | 分析成果保留 Dataset/Result 版本、地类字段、单位、面积口径、质量与来源，供制图引用 | 保持已规划的 GeoPackage/CSV 成果交付；专题样式不改变统计分母、分析筛选或分类映射 |
| Phase 3 | 完成既定正确性、任务恢复、规模与安装验收 | 专业制图不替代这一步，也不因新增远期任务推迟基础分析的独立验收 |

| Phase 4C | CART-05：高级标注/坐标网、出版预设、TIFF/SVG 和高级 PDF | 明确各输出格式支持的效果、字体策略和栅格化边界，完成目标纸幅与实际输出尺寸验收 |
| Phase 5 | CART-06：Cartography Skills 与 Agent 制图建议 | 无 Agent 时的手工与模板流程已稳定，结构化建议可验证、预览、采纳、撤销并复现 |

Phase 4A 不依赖 Hillshade 或在线影像。先提供可用成果图，避免地形效果和供应商适配阻塞用地工作流。

## 3. 程序与 Agent 边界

| 层次 | 职责 | 必须保留的限制 |
| --- | --- | --- |
| Design System | 配色、物理字号/线宽、版式规则、NoData、图例和主题预设 | 预设作为可版本化的数据配置；用户能覆写软规则，不能绕过来源、完整性和坐标等硬校验 |
| Cartography Spec | 数据版本引用、样式、分级、地图框、布局、输出参数 | 严格 schema、字段与范围校验、版本迁移；不接受任意脚本或未经验证的数据路径 |
| Renderer | 按配置读取完整托管数据或明确筛选的成果，生成图面 | 预览和导出使用同一配置；不把当前浏览器视窗、截断的显示要素或截图作为完整成果输入 |
| Cartography Skills | 根据已确认主题与数据语义提出样式、布局和标注建议 | 输出受限的配置变更及理由；不直接修改分析数据，不执行自由生成的绘图代码 |
| Export Task | 进度、取消、资源检查、导出、重读检查和发布记录 | 复用任务与发布机制，失败/取消不覆盖既有成果，不误报完成 |

制图服务先作为现有 React/Tauri/Python 系统内的模块规划，避免提前新增常驻服务或并行地图引擎。`Cartography Spec` 是目标契约，[当前草案](cartography-spec-draft.md) 不是已实现的验证器。CART-00 探针没有修改 `shared/contracts.ts`、产品 RPC 或项目 schema；Phase 1D 的协议升级来自项目携带功能。

配置草案需涵盖：

- 不可变 Dataset/Result ID 与版本、必要的显示筛选和字段引用；显示筛选与分析筛选分别保存。
- 地图框 CRS、范围、旋转、纸面尺寸；`mm`/`pt` 用于布局与字体，像素由输出尺寸和分辨率换算。
- 图层顺序、可见性、符号、透明度、受支持的混合模式、标注及缩放范围。
- 分级算法/版本、统计所用数据范围、固定断点、类别代码/名称、单位、NoData 与其他未分类状态。
- 标题、图例、比例尺、指北针、坐标网、注记、来源、日期与可选 Logo。
- 主题和配置版本、字体/图像资源、衍生地形参数、输出格式/色彩空间及渲染环境版本。
- 导出记录中的实际像素/纸面尺寸、渲染器版本、输入指纹、警告与栅格化部分。

## 4. 可执行任务

### CART-00：契约与渲染选型探针（实验完成）

已完成内容见 [Cartography Spec 草案](cartography-spec-draft.md)、[实测证据](verification-cartography-probe.md) 和 [可执行探针说明](../scripts/cartography-probe/README.md)。两条路径读取同一份 2,103 要素的完整合成样本，验证带洞/多部件面、投影、中文、透明度和 NoData。OpenLayers 输出 PNG；Python 输出包含矢量面、可检索嵌入中文及一幅栅格的 PDF，并通过独立冻结 EXE 检查。最终浏览器证据独立核对实际发送的字体/场景/图片字节，资产不匹配会在启动浏览器前拒绝。

暂定继续评估“OpenLayers 栅格预览 + Python 混合文档输出”的有边界组合。浏览器 PNG 的 DPI 元数据、两种渲染器在更复杂样式上的一致性、可分发中文字体、产品任务取消/恢复和大纸幅预算仍需后续实现；探针使用的库保持隔离，未锁定为产品依赖。以下是原实验目标及后续深化边界：

- 使用中文注记、带洞/多部件用地面、投影坐标、半透明叠加和一幅栅格的小样，对比候选渲染路径。
- 路线 A：受控的专用离屏 OpenLayers 渲染，可复用交互样式，重点验证资源加载完成、超大画布、字体与输出栅格化。
- 路线 B：Python 文档渲染路径，复用 GIS 数据服务并采用成熟的绘图/PDF 库，重点验证样式和标注与预览一致、原生依赖及包体积。
- 按输出能力和实测结果选定路径或有边界的组合；未验证前不承诺“全矢量 PDF/SVG”。PyQGIS 仅在现有路线不能满足明确验收条件时再评估，不提前增加运行时。
- 明确各格式能力和任务资源预算后再锁定依赖。现有交互地图的 2,000 要素/100,000 顶点限制不能直接作为完整出图限制；另设有界、可取消的导出执行策略。

### CART-01：主题、专题样式与基本标注

本轮CART-01A实现单一符号、明确的手动类别、NULL/其他、线宽/点半径、
Planning/Publication起始预设、图例及带revision的保存/恢复。图例不代表类别
发现或全量覆盖。后续CART-01B优先补资源有界的类别发现和数值分级；字段
标注、比例尺可见范围及下列完整要求仍是待办。每个子阶段另选授权范围。

- 基于已有单色/分类渲染，加入有单位和端点定义的分级样式、线型/线宽、点符号、基本字段标注、描边及比例尺可见范围。
- 首批主题为 Planning（土地利用成果）与 Publication（克制的论文表达）；Terrain 在 4B 加入，自定义主题可保存和重开。
- 首批分级支持手动、等间距、分位数；自然断点和标准差后续按样本加入，采用成熟库并固定算法版本。重值、常数列、空列和极端值均有明确行为，不强行凑足级数。
- 地类代码即使为数字也可能是类别；根据用户确认的字段语义选渲染器，不凭列类型自动批准。正式地类配色使用已选标准及其版本，不自动替换成审美色带。
- 连续量、类别和带有业务中点的正负偏差分别选用合适色带。图例显示真实断点、边界归属、单位与分级方法；批量或多时点比较可固定共同断点。
- NoData、数值零、合法类别、未匹配类别及显示筛选后的排除项分别处理，图面与图例一致；颜色之外可选线型/纹理，以支持色觉差异和灰度阅读。

### CART-02：基础 Layout 与 PNG/PDF

- 独立的 Layout View 与可保存的地图框，首批支持 A4/A3 横纵向、标题、图例、比例尺、指北针、来源、日期和注记。导出前可预览最终纸幅。
- 地图框采用明确适用的投影与范围；比例尺按实际纸面尺寸和声明的距离口径生成，不能直接把 EPSG:3857 的坐标米当作处处等长的地面米。
- 指北针说明真北/格网北/图面方向的约定并与地图旋转一致；比例尺与范围联动，必要时标注比例尺适用位置和范围失真限制。
- 首批 PNG 和 PDF 支持指定纸幅、像素与分辨率；提供适用的 300 DPI 预设，不将其解释为所有期刊的统一要求。PDF 允许明确记录的矢量/栅格混合输出。
- 导出前检查数据版本、完整性、字体、图例、比例尺、来源与资源加载；临时文件通过检查后才发布。提供取消和清晰的资源超限错误。
- 预览可采用降分辨率或简化缓存，正式输出必须读取冻结的完整配置和数据；不能把当前屏幕被截断的显示集合无提示导出。

### CART-03：地形与影像表现

- 采用成熟 GIS 算法生成 Hillshade、高程着色及后续等高线；保存 DEM 版本、波段比例/偏移、工作网格、水平/高程单位、重投影/重采样、方位角、高度角和垂直夸张系数。单位换算与视觉夸张分别记录，经纬度 DEM 不使用适用于所有纬度的固定“度到米”系数。
- 高程单位、垂直基准、NoData/掩膜与工作 CRS 不明时给出限制；计算坡向/光照所需的水平和垂直单位必须明确。未知垂直基准不能被自动补造。
- 单向 Hillshade 是局部光照表现，不等同于真实太阳辐射、地形投射阴影或坡度分析成果；垂直夸张明确标识。派生文件是可追溯的新产品，不回写 DEM。
- 支持高程色带、影像亮度/对比度/饱和度与透明度；先实现 Normal/Multiply，经验证再加入 Overlay/Soft Light/Screen。
- 加入栅格波段/RGB 组合选择、数值拉伸与分类显示；保存拉伸方法、统计范围、上下限及分类断点，NoData 不参与有效值统计，色带与图例同步。缩放/平移不隐式重算已固定的拉伸范围，显示分类不回写原始像元。
- 地形增强作为可预览的组合预设；层序和强度可修改，不为所有专题自动添加地形。检查实际合成颜色的辨识度与图例含义，必要时保持主专题不透明，避免背景造成类别混淆。
- 分类栅格和连续高程/影像分别选择适用重采样方法；掩膜和 NoData 不被重采样成有效类别或零值。衍生缓存按输入版本与参数失效。

材料中的热力图先列为后续候选：屏幕点聚合的视觉效果与可解释的核密度/人口密度结果分别命名。后者需要独立的分析方法、单位、参数和验收，不能由“美化地图”隐式生成统计结论。

### CART-04：可选背景来源

- 本地卫星/航空 GeoTIFF 优先；XYZ、WMTS、WMS 按供应商和协议分批适配，记录显示 CRS、来源、日期、署名和允许的缓存/导出范围。
- 用户凭据与服务访问采用现有受控原生边界，密钥不写入共享制图配置或导出清单；文件选择与本地路径不由 Agent 随意扩展。
- 验收网络失败、缺瓦片、离线缓存、最大请求尺寸、跨域/资源访问和导出授权限制。背景不可用时显式阻止或由用户选择带缺失说明的输出，不能静默缺图。

### CART-05：高级制图与出版输出

- 扩展标签优先级/碰撞避让/比例尺范围，支持行政边界和道路的规则化层级；规则引用用户明确的等级字段，不猜测道路或行政级别。
- 加入经纬网、投影坐标网、插图/多地图框及受控批量模板；每个地图框拥有独立 CRS、范围和比例尺。
- 追加 TIFF、SVG 和更完整的 PDF 输出，按能力表说明透明度、字体、混合模式、标注和图像嵌入的支持范围。600 DPI 必须在明确纸幅与内存上限内验证。
- 区分普通排版 TIFF 与可定位的 GeoTIFF；带纸面装饰的整页输出不能随意写成单一地理参考。需要地理参考地图框时单独验证 CRS 和仿射变换。
- PDF/SVG 中栅格底图、混合效果或被栅格化的图层放大后仍受像素限制。验证有效分辨率与实际矢量对象，不能用扩展名承诺“1000% 清晰”。
- 中文字体缺字/替换、嵌入许可、PDF 字体嵌入、SVG 的字体/转路径策略必须显式检查；转路径会影响文本检索和可访问性。首批色彩空间明确为 sRGB，印刷色彩管理另行验收。
- 将“Nature 风格”作为 Publication 的可配置预设：记录目标期刊、图型、版心、字号/线宽/格式规则来源与核对日期。它不代表 Nature 官方认证，也不替代投稿要求或规划成果规范。

### CART-06：制图顾问与配置建议

- 复核选用的制图/Nature Skill，将可计算规则放入主题/验证器，将专题选择、主次、标签密度和版式建议留给顾问；不把当前开发环境的 Skill 可用性当作安装版产品能力。
- Agent 读取最少必要的元数据与获准预览，生成结构化配置变更及理由。默认保持本地工作流，外部模型获取数据需有明确的范围和用户授权。
- 硬校验拒绝未知字段/数据版本、非法值、任意代码、未经允许的资源及丢失必要来源说明的建议。
- 提供前后预览、变更清单、采纳/拒绝和撤销。分类断点、可见类别与筛选变化单独提示；数据值、分析 CRS、几何、统计分母和结果版本不可由美化操作修改。
- 保存最终配置、主题/Skill/模型版本及建议来源，重开和重导出不需要重新询问模型。模型不可用或建议无效时仍能继续手工与模板制图。
- “一键优化”表示生成候选配置并通过检查，不自动声称达到规划审查或期刊发表标准。

## 5. 分阶段验收用例

每个阶段在实施前为其支持的纸幅、比例尺、要素/顶点数、栅格尺寸、字体和输出格式固定验收样本及容差，不在失败后放宽标准。

| 用例 | 通过条件 |
| --- | --- |
| 数据不变与可复现 | 改主题、地形、布局和 Agent 建议前后，输入几何/属性/版本及分析统计值一致；重开后无需模型即可重出同配置图面 |
| 完整导出与任务故障 | 使用超过交互显示上限的已知样本核对输出内容；预算不足明确拒绝，取消/断电/写盘失败不留下被登记为成功的半成品 |
| 分级与图例 | 前导零代码、NULL、零、未分类、重值和极值有预期图例；栅格波段、拉伸范围及断点保存重开一致；固定断点跨年份可比，图例、标注单位与结果一致 |
| 投影与纸面比例 | 已知控制距离在给定地图框尺寸、投影和旋转下对应正确比例尺；网格、指北针及指示的距离口径通过独立核对 |
| 地形与重采样 | 已知坡面、平面、米/英尺等价 DEM、波段比例/偏移、非正方形像元、高纬度与 NoData 边缘核对光照方向和单位换算；分类重采样不产生新类别 |
| 输出质量与字体 | 核对实际纸幅/像素/DPI、PDF/SVG 矢量与栅格部分、中文缺字/字体嵌入；目标尺寸下无不合理遮挡、裁切或图例缺项 |
| 底图失败与权限 | 离线、瓦片缺失和禁止导出时按配置阻止或明确标记；没有获准的外部上传、隐式下载或凭据泄露 |
