## 可完成的工作

1. 选择两个已登记的 Polygon/MultiPolygon 数据集，执行研究区裁剪或两层相交。
2. 明确地类字段、分类标准/版本、分析投影及其适用理由。
3. 查看结果图斑和分页分类面积表，导出包含完整追溯记录的 GeoPackage，
   或另行导出统计 CSV；项目保存、另存与重开保留结果和输入版本引用。

输入是完整不可变快照，不使用当前视窗、显示简化几何或未经声明的属性过滤。
原始台账面积和所有来源文件保留，输出只携带源内部 ID、原始分类值、输入
版本引用、结果 ID 及几何面积；不宣称自动复制全部原始属性到结果。

## 分析口径

- 面积为显式选择的二维投影下的平面几何面积；单位转为平方米，可显示
  公顷和亩。拒绝未知、经纬度、Web Mercator、三维/复合 CRS；投影必须
  有可核查的适用范围，用户填写适用理由。记录完整 WKT、线性单位转换、
  PROJ 操作、精度的已知/未知状态、格网与库版本；禁止 ballpark 回退。
- 分类字段首版限定字符串，保留 `001`、空串和空白；NULL 是独立未分类组，
  与文字 `NULL` 区分。分类标准由用户填写，程序不猜测国家/地方分类体系。
- 裁剪的第二层是研究区，先取其并集（最多 10000 要素/1000000 顶点），
  避免重叠边界重复计数；输出用地与该并集的正面积交集，按左侧地类汇总。
- 两层相交按左右分类组合汇总；第二层的几何并集是研究区分母。左右输入
  均要求同层图斑没有正面积重叠，因此第二层面积求和等于其并集面积，无需
  对 50 万图斑执行一次无界全局并集。
- 当前采用严格策略：分类输入（裁剪左侧、相交左右两侧）的空/无效几何、
  同层重复或任何正面积重叠均阻止统计；裁剪研究区允许重叠并先取并集。
  提供有界示例 ID；不自动修复、去重、吸附、分配重叠区或删除碎面。
  同地类重叠也需先处理。本阶段不交付重叠优先级、同类融合或修复工具。
- 通过互斥校验后，输出逐记录面积和去重覆盖面积相等，分别记录并解释。
  同时提供占研究区面积和占有效覆盖面积两种比例；覆盖为零时后者为 NULL，
  未覆盖研究区单独报告。边/点接触不形成面成果，并记录接触计数。
- 不设置业务容差掩盖重叠。测试中的浮点容差预先固定，只用于核对解析答案，
  不是测绘精度声明。保存未四舍五入的双精度面积，输出不隐式改变口径。

## 结果和存储

每次成功分析生成一个独立 VectorDataset（driver `SpatialAnalysis`），
新的不可变 `datasets/<UUID>.gpkg` 同时保存结果面、非空间统计表和版本化
AnalysisRecord。数据集来源元数据保留两份输入 ID/版本、analysisId 及算法
类型，完整计算记录位于 GeoPackage 中，避免工作区响应随统计行数膨胀。
Analysis 与结果数据集身份分开；失败/取消仅留 Task，不登记部分结果。

复用现有暂存、无覆盖发布和 SQLite 登记事务。所有权、完整性及恢复必须
覆盖整个 GPKG，因此统计表与几何不存在分别发布一半的状态。CSV 是独立
可取消导出任务，目标必须不存在；原始分类文本不插入公式或修改前导零。
另存/移动后通过当前项目内输入 ID/版本解析分析来源，不依赖旧绝对路径。

公共方法：`analysis.run` → Task(kind analysis)，`analysis.result` →
AnalysisResultPage，`analysis.exportCsv` → Task(kind export)。精确字段以
`shared/contracts.ts` 为准。schema 1–5 先备份再迁移至 6。

## 响应性与资源保护

保留 React/OpenLayers + Tauri + Python；采用流式导入、空间索引和分批叠加。
把全量 GeoPandas overlay 作为主路径会放大中间内存；现在引入数据库服务器
或分布式集群则超出个人 EXE 的部署目标，两者都不选为本阶段默认方案。

- 普通矢量目标上限：每数据集 500000 要素、10000000 顶点、单几何 100000
  顶点、512 MiB 规范化快照；保留字段/响应预算。先流式写出及流式往返校验，
  不只上调常量。属性分页覆盖末尾记录。
- 分析预算：左右各遵循输入上限，累计候选对最多 5000000，输出最多
  500000 面、10000000 顶点、512 MiB，最多 10000 分类组合。
  空间索引逐要素/小批量查询，不创建完整笛卡尔候选数组。
- 独立于 RPC 轮询的 worker 监控：最长 900 秒，进程树内存预算 2 GiB；
  超限终止并返回具体错误。协作取消后最多等待 2 秒，再终止/回收进程。
  没有新进度不等于死锁，不用虚构百分比判断任务存活。
- 数据查询进入可终止的独立只读进程，操作预算 2 秒、内存预算 1 GiB；
  超时只回收查询进程，保留项目和计算任务。冷启动可独立预热，未就绪时
  返回明确状态，不无限排队。SQLite 扫描另有进度中断保护。
- 全局前端请求队列有界，控制请求优先于待发送显示请求；视窗/属性/选择
  请求最多保留当前请求和最新一次待执行请求。隐藏工作区停止发起数据查询。
  Rust 排队等待也计入超时，不能等获取锁后才开始计时。
- 地图仍按视窗与聚合图层预算显示，不能把 50 万几何一次送到 React/Canvas。
  数据结果完整性与地图截断分开；鼠标坐标更新节流，属性/统计表分页。
- 大文件发布核对必须保持控制请求可响应：分离后台核对/发布生命周期，
  取消与项目关闭协调回收；不得跳过哈希验证以换取速度。

## 压力验收

在本机记录 CPU、16 GiB 实际物理内存、Windows/磁盘与运行时版本。
固定随机种子和解析答案，分 1000、10000、100000、250000、500000 图斑
执行导入、裁剪/统计、查询末页、导出与重开。CI 使用较小固定级别及资源
失败/强制取消回归；500000 完整工作流由本机源码/最终冻结与原生界面验收。

预先设置测量门槛：计算期间 DOM 交互反馈 p95 ≤150ms，前端事件循环最大
停顿 ≤500ms，轻量任务状态 p95 ≤1000ms，取消到终态 ≤5s；实际超出时
查明原因并修复，不能执行后放宽门槛或把未完成计算称为通过。记录查询
延迟/请求峰值、各进程峰值内存、输入/输出要素及顶点、阶段耗时。

另外构造高顶点复杂面、密集重叠、候选爆炸、超预算、永不返回的 worker、
无轮询超时、发布核对中取消和进程崩溃。应明确失败或取消、保留原数据和
已有成果，且下一个小任务成功。50 万简单图斑通过不等于任意复杂度的
50 万图斑都可计算，压力失败的保护测试也不能替代成功规模测试。

单元解析样本覆盖孔洞、多部件、边/点接触、空交集、研究区重叠、同类/跨类
重复重叠、NULL/空串/前导零、混合投影与英尺单位、未知/错误 CRS、缺失
格网、无效几何及无静默修复。版本迁移、任务恢复、原始哈希和 GPKG 重读
必须验证。真实规划数据、ArcGIS、独立 Windows、离线/升级仍单列待验收。
