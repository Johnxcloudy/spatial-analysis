# Phase 1C Implementation Plan

**Goal:** Deliver native GeoTIFF import, display, pixel inspection and exact export.
**Architecture:** Rasterio owns raster IO and display warps; Python project storage
owns immutable snapshots; Tauri routes bounded RPC; OpenLayers mixes image and
vector layers. Reuse the existing feature branch and worker publication model.
**Tech Stack:** Rasterio/GDAL/PROJ, NumPy, SQLite, Tauri/Rust, React/OpenLayers.

## Global Constraints

The binding scope, resource limits and RPC shapes are in docs/phase-1c.md and
shared/contracts.ts. Use synthetic inputs only, never overwrite sources or user
projects, and keep generated artifacts ignored. Application 0.4.0, public protocol
4, project schema 4, worker protocol 3. Each worker owns disjoint files and reports
tests; primary integrates, reviews and handles all Git operations.
