# Phase 0 Implementation Plan

> For agentic workers: use subagent-driven-development for independent components and test-driven-development for storage and protocol behavior. The user has authorized execution and Git deployment.

Goal: deliver a Windows desktop foundation that calls a bundled local GIS engine, creates/saves/reopens projects and runs verifiable synthetic GIS diagnostics.

Architecture: React and OpenLayers diagnostic view call a Tauri command; Tauri owns a persistent Python console sidecar using bounded newline JSON-RPC. Python owns locked SQLite project metadata and genuine GIS diagnostics. PyInstaller onedir is bundled as a Tauri resource directory.

Tech stack: Tauri 2, React, TypeScript, Vite, OpenLayers, Python 3.12, GeoPandas, Shapely, pyogrio, pyproj, Rasterio, SQLite, PyInstaller.

## Global Constraints

- Phase 0 only. No user dataset import, general layer manager, thematic analysis or AI.
- Preserve existing docs and Git history; work on feat/phase-0, no force pushes.
- App version 0.1.0, project schema 1 and protocol 1. Contracts: shared/contracts.ts and shared/protocol.md.
- Genuine IO/computation and explicit errors; no simulated GIS success.
- Chinese UI, efficient desktop workbench layout, responsive without overlapping controls.
- Deployment verification distinguishes developer-machine testing from clean Windows testing.
